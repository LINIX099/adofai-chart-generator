## 1. 记谱约定（从主人自己的谱子里反推出来的）

```
每一个字符 = 1 格 = 一个 travel-180 平格的时长
  O = 普通格子   → 1 格，travel 180
  X = 双押       → 1 格，两格 [30, 150]   （Σtravel = 180 = 一格，**时值完全一样**）
空格 = 分组，不占时间
```

### 1.1 「1 格 = 60ms」是怎么定的

主人的 `out/双押交互.adofai`（101 层 · 单一 `SetSpeed ×4`）解出来：

```
有效单元（5 格）: 30, 150, 180, 180, 180
dt（ms）        : 10,  50,  60,  60,  60        ⇒ **一格 = 60ms**
对应记谱        :  X    O    O    O         （4 字符 = 4 格 = 240ms）
```

⇒ 与 `docs/31` §2.2 的读法**完全一致**：`4k base ⇒ cbpm = 4 × tbpm`；
`250bpm 的 16 分 = 1000bpm 的 4 分 = 60ms` ✓ 所以「一个字符 = 一个 4 分音」= 60ms。

★ 顺带：主人的例子 `XOOOXOOOXOOO` 就是 `双押交互` 的写法本身，
`OOX OOX OOX` 是它的三格版（hemiola）。

### 1.2 主人的谱子里还藏了 Twirl 的用法

```
Twirl 落在第 6、11、16、21… 格 —— **每个单元的第一格**（第一个单元不翻）
⇒ 相邻单元用**相反手性**编码（raw 交替 330,210 ↔ 30,150）
```

这正是 `docs/31` #11 用户原话「**（Twirl）为了不叠起来**」的落地方式。

## 2. ★★ 核心不变量（「塞双押不破坏排版」的全部秘密）

```
一个双押 = 两格 [θ, 180·W − θ]        Σtravel = 180·W
```

（`docs/31` §2.2.2 的统一公式；塔 / 斜向 / 交互 / 强弱**都是它**，只是 W 和间隔不同。）

| 写法 | W（占几格） | 两格 | 上下文间隔 |
|---|---|---|---|
| **双押交错**（`双押交互`） | **1** | `[30, 150]` | 后面跟 3 个 `180` ⇒ 每 4 格一个 |
| **斜向单元** | **1** | `[30,150]` ×2 背靠背 | 每 1 格一个（连续双押） |
| **双押塔** | **2** | `[30, 330]` | 无间隔，塔即循环 |
| **强弱** | **0.5** | `[30, 60]` | 紧邻（5 连 = 9 对） |

**⇒ 双押吃掉的时间 = W 个平格的时间，一分不多一分不少** ⇒ **它不会把后面的音推走**。

### 2.1 给求解器的三条规则

| # | 规则 | 为什么 |
|---|---|---|
| **①** | **双押只能落在「平格」上**（那个位置本来该是 `travel = 180`） | 落在拐角上 ⇒ `Σtravel ≠ 180W` ⇒ 时值就崩、后面的音全被推走 |
| **②** | **相邻双押必须用相反手性**（Twirl 翻奇偶） | 双押会多出**一格**（2 格 vs 1 格）⇒ 路径有一个"侧跳"。同手性累积 ⇒ 路径一边倒、叠在一起（我们 `flower_dp` 的「占地 1.9 格²」就是这么来的） |
| **③** | `θ ∈ {15, 30, 60}`（薄角）、`W` = 占几格；**同一段里 W 与 θ 保持一致** | `θ` 一变，两格的形状就变；人类谱里一段只用一套 |

★ 规则 ① 还解释了为什么「**支线（直线）配置和正方形配置**」是双押的主要宿主：
它们是**平格最多**的两族（直线全 180；正方形 `90·90·90·90` 里仍有大量平格可插）。
