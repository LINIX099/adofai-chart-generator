# 70 · 镜头调度公式：**呼吸 + 漂移 + 聚焦**（轮指 / 采bpm 的主方案）

> 用户 2026-10 定稿：
>
> > 「level2.2 的长镜头**非常好**，可以把**公式梳理出来了**。
> >   以后这个就是**轮指、采bpm** 这种场景主要使用的镜头调度方案」

本文把 `out/运镜验收谱v4-Sinkhole2/level2.2.adofai` 那套调度**写成公式**，
自足、可照抄、可测试。参考实现 = `tools/apply_camera_gs2.py` 的
`drift_tail()` / `stair_zones()` / `_zone_weight()`。

**当前状态：公式 + 离线工具已有；`core/camera.py` 仍未实现**（等主人说接线）。

---

## 0. 一页速览

| 层 | 公式 | 峰值 |
|---|---|---|
| **漂移 · 位置** | `p₀ + Σ Aᵢ·sin(2πu/Pᵢ + φᵢ)`（x、y 各两组） | x 峰峰 3.0 格 / y 峰峰 2.4 格，**13 / 11 秒一个来回** |
| **漂移 · 旋转** | `Σ Aᵣ·sin(2πu/Pᵣ + φᵣ)`（两组） | ±6°，17 / 9 秒一个来回 |
| **呼吸 · 缩放** | `[Z_m + A_z·sin(2πu/P_z + φ_z)]·(1 + ε·(−1)^k)` | 220 ± 45，再 ±11% |
| **网格** | 每 `S = 8` 拍一条、每条 `D = 16` 拍 | `D = 2S` ⇒ **任意时刻两条在跑 ⇒ 永不静止** |
| **ease** | 全部 `InOutSine` | **零过冲、零硬切** |

---

## 1. 记法与输入

| 符号 | 含义 |
|---|---|
| `base` | 谱面 `settings.bpm`（**拍长 `τ = 60000/base` ms**） |
| `p₀`, `z₀`, `r₀` | 谱面基准位：`settings.position` / `settings.zoom` / `settings.rotation` |
| `[F₀, F₁]` | 要铺运镜的格区间 |
| `T[f]` | **到达第 f 格**的时刻（ms）—— 由 `core/solve.times_from_chart` 那套时间模型算 |
| `u` | 段内墙上时间（**秒**）：`u(t) = (t − T[F₀]) / 1000` |

★ **`MoveCamera.duration` 的单位是拍**，拍长只由 `base` 决定、**与 `SetSpeed` 无关**。
所有时值都按拍写，不按格算（`docs/67` §5）。

---

## 2. 网格

```
t_k = T[F₀] + k · S · τ            k = 0, 1, 2, …
f_k = max( F₀, min( F₁, max{ f : T[f] ≤ t_k } ) )        ← 落格
duration_k = D
```

| 常数 | 值 | 为什么 |
|---|---|---|
| `S`（步长） | **8 拍** | 落格后每步 ≈ 0.53 s；再密就"跳"，再疏就"顿" |
| `D`（时值） | **16 拍** | `D = 2S` ⇒ **任意时刻都至少有一条补间在跑** ⇒ 永不静止 |
| `ease` | **`InOutSine`** | 起停都是零速度，两条重叠时接缝处最柔 |

★ **不变量**：`S·τ > 该处单格时长` ⇒ 落格严格递增，**不会同一格发两条**
（`travel = 90` 的折弯段单格只要 0.5 拍，仍远小于 8 拍）。

---

## 3. 采样时刻（★ 一处必须分清）

| 量 | 采样点 | 为什么 |
|---|---|---|
| **漂移 / 呼吸** | 补间**中点** `û_k = u(t_k) + D·τ/2000` | 一条补间代表它"走到一半时"的位置，链起来才平滑 |
| **聚焦权重** | **事件自己的格号 `f_k`** | ★ 用中点会**提前 `D/2` 生效**：折弯段 `travel=90` ⇒ 1 格 = 0.5 拍 ⇒ 16 拍的补间跨 **32 格**，实测把折弯聚焦区**截掉一半** |

---

## 4. 漂移层（慢 · 连续 · **永不停**）

```
P(u) = p₀ + [ Σᵢ Aˣᵢ·sin(2πu/Pˣᵢ + φˣᵢ) ,  Σⱼ Aʸⱼ·sin(2πu/Pʸⱼ + φʸⱼ) ]
R(u) =       Σₘ Aʳₘ·sin(2πu/Pʳₘ + φʳₘ)
```

| 轴 | `(周期 s, 幅度, 相位)` | 峰峰 | 观感 |
|---|---|---|---|
| **x** | `(13.0, 1.00, 0.00)`、`(7.3, 0.50, 1.70)` | **3.0 格** | 十几秒一个来回 |
| **y** | `(11.0, 0.80, 0.90)`、`(6.1, 0.40, 2.40)` | **2.4 格** | 与 x **不同周期** ⇒ 轨迹不打结也不重复 |
| **rot** | `(17.0, 4.0, 0.40)`、`(9.0, 2.0, 2.10)` | **±6°** | 同上，三个周期互质近似 |

★ **两个不同周期叠加**是这套的要点：单周期会看出"摆动"，双周期才是"漂"。
★ 相位都是错开的（`0 / 1.7 / 0.9 / 2.4 / 0.4 / 2.1`），避免 x/y/rot 同相一起冲。

---

## 5. 呼吸层（缩放）

```
Z(u, k) = [ Z_m + A_z·sin(2πu/P_z + φ_z) ] · ( 1 + ε·(−1)^k )
```

| 常数 | 值 | 含义 |
|---|---|---|
| `Z_m` | **220** | 缩放中位 |
| `A_z` | **45** | **慢基线**摆幅（15 秒一个来回）⇒ `175 ~ 265` |
| `P_z` | **15 s** | 慢基线周期 |
| `φ_z` | **0.7** | 相位 |
| `ε` | **0.11** | **呼吸**幅度，逐条交替 `(−1)^k` |

⇒ 每 **1.07 s** 一涨一落（≈ 0.94 Hz），瞬时缩放约 `156 ~ 294`。

★ 慢基线 + 快呼吸**两层**：只有呼吸会像"心跳"，只有基线会像"呼吸不畅"。
★ `(−1)^k` 直接挂在网格序号上 ⇒ 呼吸与网格**锁相**，不需要额外的定时器。

---

## 6. 聚焦 A：**折弯循环段**（连续 90° 折弯）

### 6.1 找区

```
travel[f] ∈ {90, 270} 的连续格算"折点"；中间**最多夹一个 180**
一串的折点数 ≥ 4 才算
相邻两串间隔 ≤ 40 格 ⇒ 并成一个"聚焦区"
```

实测（Sinkhole）：5 串，其中 4 串在 **2560..2647**，并成一个 88 格的区。

### 6.2 权重（边缘线性渐变）

```
w(f) = clamp( maxᵢ wᵢ(f), 0, 1 )

        ⎧ 1                        aᵢ ≤ f ≤ bᵢ
wᵢ(f) = ⎨ 1 − (aᵢ − f)/L           aᵢ − L ≤ f < aᵢ        L = 6 格
        ⎩ 1 − (f − bᵢ)/L           bᵢ < f ≤ bᵢ + L
          0                        其它
```

### 6.3 叠加（★ **平滑加权，不是硬切**）

```
Z ← lerp( Z ,  Z_f , w )      Z_f = 200 + 9·sin(2πu/2.4 + 0.3)
R ← lerp( R ,  R_f , w )      R_f = 4·sin(2πu/3.2)
P ← p₀ + (P − p₀)·lerp(1, 0.35, w)
```

| 常数 | 值 | 为什么 |
|---|---|---|
| 聚焦缩放 | **200 ± 9** | 用户口径「温柔一点，只拉近到 **190~210**；**不换帧**」 |
| 对基准 | 本谱基准 `250` ⇒ **拉近**（★ 本项目里 zoom **越大越远**） |
| 轻摆 | **±4°**，周期 **3.2 s** | 有"活气"但不晕 |
| 漂移增益 | **0.35** | 聚焦时把漂移压到三成五 —— 不然"聚焦"会晃 |

## 7. 聚焦 B：**结尾聚焦球**

**触发**：最后一个折弯区的**下一格** `F_e = b_last + 1`（= 「速度完全降下来之后」；
Sinkhole 里正好是 `cur` 从 900 掉到 450 的那一刻）。

```
e(f) = clamp( (f − (F_e − L_e)) / L_e , 0, 1 )        L_e = 4 格

Z ← lerp( Z ,  Z_e , e )      Z_e = 150 + 4·sin(2πu/2.8 + 0.9)
R ← lerp( R ,  0   , e )
P ← lerp( P , [0,0], e )      ← ★ 位置收到**球本身**
```

★ 两处**必须**一起做：

1. **不发出场归位事件** —— 归位会把镜头从球上拉回基准位，正好毁掉这个收尾；
2. 留 `±4` 的呼吸 —— 否则结尾是**死画面**（与「永不静止」不变量冲突）。

## 8. 一条事件的完整字段

```
floor       = f_k

duration    = D = 16 拍

zoom        = Z''               ← 显式给出，**绝不为 null / 0**

ease        = "InOutSine"

```

## 9. 不变量（自检会拦）

| # | 不变量 | 依据 |
|---|---|---|
| 1 | `zoom` **永不为 `null` / 0** | `docs/64` §8.6.5（v1 黑屏的根因） |
| 2 | 四个字段**全部显式** | 同上；留空会被读成 0 |
| 3 | **零 `duration=0`**、零过冲 ease | 用户：「少用甩尾运镜」 |
| 4 | **任意时刻 ≥1 条补间在跑** ⇒ 位置变化间隔 ≤ `S` 拍 ⇒ **永不静止** | 实测最长静止 **0 s**（老方案 4.41 s） |
| 5 | 覆盖格数 ≤ 段长 + 3 | 不溢出到下一段 |
| 6 | 落格严格递增 | `S·τ >` 单格时长 |

## 12. 跨谱面复用（换算三件套）

把一套参数从谱面 A 搬到谱面 B（实测走过：国士 base 340 / zoom 300 → Sinkhole base 900 / zoom 250）：

| 量 | 换算 | 为什么 |
|---|---|---|
| **位置** | **原样** | `position` 的单位是**格**，与 `base` / `zoom` 无关 |
| **缩放** | `× z₀(B)/z₀(A)` | 保的是「相对基准位的观感」，不是绝对值 |
| **时值（拍）** | `× base(B)/base(A)` | 拍长只由 `base` 决定 ⇒ 乘这个比例**墙上时长不变**，快慢观感才一致 |
| **落点** | 按**段内进度**对齐 | 两段墙上是「同一位置的长段」时最稳 |

★ 第 3 条最容易错：照抄「2 拍」在 base 900 上会**快 2.6 倍**，直接变成甩尾。

## 14. ★ 边界与待定

1. **本方案只负责"怎么动"，不负责"什么时候用"** —— §11 的分派还没接线。
2. `Z_m = 220` 等常数是**按 Sinkhole（基准 zoom 250）标定的**；
   换谱面时按 §12 的 `z₀(B)/z₀(A)` 换算，**不要照抄绝对值**。
3. **`S = 8` / `D = 16`** 是按 `base = 900` 选的（≈ 0.53 s / 1.07 s）。
   `base` 差很多时应当按 §12 第 3 条换算，或重新标定。
4. 折弯聚焦**没有**改帧（仍是 `Player`）—— 用户选的「温柔档」。
   国士 `3407..3415` 那种 `Tile` 帧 + `zoom 134` 的**贴脸档**是另一个变体，本轮没用。
5. `ε = 0.11` 的呼吸是**逐条交替**（0.94 Hz）；如果要更慢的呼吸，
   改的是 `P_z` 而不是 `ε`。
