## 1. 「呼吸」是哪几层

`docs/70` 的方案有**三层**：漂移 · 呼吸 · 聚焦。
本轮**只接前两层**（用户：「其他方案等待完全成熟后接入」）：

```
漂移·位置   P(u) = p₀ + [ Σᵢ Aˣᵢ·sin(2πu/Pˣᵢ + φˣᵢ),  Σⱼ Aʸⱼ·sin(2πu/Pʸⱼ + φʸⱼ) ]
漂移·旋转   R(u) =       Σₘ Aʳₘ·sin(2πu/Pʳₘ + φʳₘ)
呼吸·缩放   Z(u,k) = [ Z_m + A_z·sin(2πu/P_z + φ_z) ] · ( 1 + ε·(−1)^k )
```

| 轴 | `(周期 s, 幅度, 相位)` | 峰峰 |
|---|---|---|
| x | `(13.0, 1.00, 0.00)`、`(7.3, 0.50, 1.70)` | 3.0 格 |
| y | `(11.0, 0.80, 0.90)`、`(6.1, 0.40, 2.40)` | 2.4 格 |
| rot | `(17.0, 4.0, 0.40)`、`(9.0, 2.0, 2.10)` | ±6° |
| 缩放 | `Z_m=220 · A_z=45 · P_z=15s · φ_z=0.7 · ε=0.11` | 156 ~ 294 |

网格：每 `S = 8` 拍一条、每条 `D = 16` 拍（`D = 2S` ⇒ **任意时刻都有补间在跑 ⇒ 永不静止**），
`ease = "InOutSine"`（零过冲），`relativeTo = "Player"`。

★ **两处最容易做错的地方**（`docs/70` §3，离线阶段实测踩过）：
**漂移 / 呼吸采样在补间「中点」** `u + D·τ/2000`；而（未来的）聚焦权重用**事件自己的格号**。

★ **跨谱面换算**：`Z_m = 220` 是在 **z₀ = 250** 的谱面上标定的 ⇒
本实现按 `zoom × 基准zoom/250` 换算（`docs/70` §12）。位置（格）与时值（拍）**原样**。

## 2. 实测（Flower Rocket，200.6 s）

| | 关（默认） | **呼吸** |
|---|---|---|
| `MoveCamera` | **0 条** | 97 条 |
| `settings` 基准位 | **一个字节不动** | `position [0,0] · rotation 0 · zoom 200 · relativeTo Player` |
| 位置完全静止最长 | — | **0.00 s** ✓ |
| 缩放范围 | — | **124.7 ~ 235.3**（无 0 / null）✓ |
| ease / duration | — | 全 `InOutSine` / 全 `16.0` ✓ |
| **按键时刻** | — | **最大差 0.000000 ms ⇒ 时序零影响 ✓** |
| 不变量违规 | — | **0 条** ✓ |

```
镜头调度：呼吸 ⇒ 97 条 MoveCamera · 覆盖格 0~1741（200.6 s）
  · 网格：97 条之间最多隔 8.50 拍（≤ 步长才叫「永不静止」）
  · **位置完全静止最长 0.00 s**（目标 0）· 漂移峰峰 位置 2.94 格 / 旋转 11.8°
  · 缩放 124.7 ~ 235.3（永不为 0 / null）
```

★ **时序零影响**是硬要求：镜头只写 `MoveCamera` + `settings` 的四个位姿键，
**绝不碰** `angleData` / `bpm` / `travel` / `Twirl`。上面那行 0.000000 ms 就是它的证据。

## 4. 不变量自检（`core/camera.py::check_events`，`docs/70` §9）

| # | 不变量 | 怎么守 |
|---|---|---|
| 1 | `zoom` 永不为 `null` / 0 | 逐条断言（v1 黑屏的根因） |
| 2 | 四个字段全部显式 | `position` / `rotation` / `zoom` / `relativeTo` 逐条写出 |
| 3 | 零 `duration=0`、零过冲 ease | `duration ≥ 0.5`；`ease` 白名单（`SAFE_EASE`） |
| 4 | 任意时刻 ≥1 条补间在跑 | `longest_still()` 量**位置完全静止**的最长秒数，目标 0 |
| 5 | 覆盖格数 ≤ 段长 + 3 | `from_floor` / `to_floor` 夹住 |
| 6 | 落格严格递增 | 二分落格；`S·τ >` 单格时长 |

★ 违规**进 `warnings` 上屏**，不静默。
