## 0. 一句话

**三押 = 同一时刻有 2 条多押轨都在响** ⇒ 把那一格（180°）**拆成 3 块**
`[θ₁, θ₂, 180 − θ₁ − θ₂]`。
**判据来自输入（轨数）· 几何是拆格 · 总 travel 不变 ⇒ 时序零偏移。**

## 2. 参考谱解码（硬事实，可复算）

**文件**：`tests/fixtures/adofai/three_press_interact.adofai`

```

  ⇒ 有效 cbpm = 250 × 4 = 1000   （= 4 × tbpm ⇒ **这份谱本身就是 4k base**）

```

有效 travel（`core/path.py` 口径：无 Twirl ⇒ `travel = (norm180(Δheading) + 180) % 360`）：

| 格 | angleData | **有效 travel** | **Δt** | 累计**按下时刻** |
| --- | --- | --- | --- | --- |
| 1 | 150 | **30°** | 10 ms | **0** |
| 2 | 270 | **60°** | 20 ms | **10 ms** |
| 3 | 0 | **90°** | 30 ms | **30 ms** |
| 4 | 0 | 180° | 60 ms | 60 ms |
| 5 | 0 | 180° | 60 ms | 120 ms |
| 6 | 0 | 180° | 60 ms | 180 ms |
| 7 | 150 | 30° | 10 ms | 240 ms ← 下一单元 |

**最小重复单元（6 格）= `[30, 60, 90, 180, 180, 180]`，合计 720° = 4 拍。**
⇒ 与 `双押交互` **完全同构**：

```
双押交互:  [30, 150]           + 180 180 180    ← 4 拍一个双押（docs/31 §2.2.2）
三押交互:  [30,  60,  90]      + 180 180 180    ← 4 拍一个三押   ★
```

★ **`30 + 60 + 90 = 180° = 正好 1 拍** ⇒ 三押**替掉一个普通格**，**总 travel 不变**。

**复算脚本**（想再验一遍就跑这段）：

```python

                   encoding='utf-8-sig'))

# 期望 [0, 30, 60, 90, 180, 180, 180] / [0.0, 10.0, 20.0, 30.0, 60.0, 60.0, 60.0]
```

## 3. 判据与几何

### 3.1 判据：`押数 = 1 + 同时有音的 dp 轨数`

| 同时有音的 dp 轨数 | 押数 | 几何 |
| --- | --- | --- |
| 1 条 | **双押** | `[θ, 180 − θ]`（**2 块**）|
| **2 条** | **三押** | **`[θ₁, θ₂, 180 − θ₁ − θ₂]`（3 块）** |
| ≥ 3 条 | 四押 / 5押 | **不做**，但**记账 + 上报**（§5）|

- 「**同一时间**」= 落在 **±`dp_tol`**（默认 45 ms）窗口内（`docs/47` §5.7 已把 `dp_tol` 的职责收窄成「配对」）。
- ★ **语义澄清**：**一条 dp 轨连续响两下 ≠ 三押**（那是两个双押）。押数**只看同时响的轨数**，不看序列。

### 3.2 几何：`[θ₁, θ₂, 180 − θ₁ − θ₂]`（W = 1）

沿用 `docs/31` §2.2.2 的统一公式 `[θ…, 180·W − Σθ]`（**最后一块吃余量**）：

```
双押  W=1:  [θ,      180 − θ]           ← 现成
三押  W=1:  [θ₁, θ₂, 180 − θ₁ − θ₂]     ← 本次（用户：W 恒 = 1）
```

## 4. 角度组合表（**只入有据可查的**）

| 窗口 | 双押 | **三押** | 出处 |
| --- | --- | --- | --- |
| 低位（**边界待定**）| 15° | **`15 · 15`**（第三块 = 150）| 语料 `15°·15°`(678)；用户「15 度三连」|
| **cbpm 1000**（参考谱实测）| 30° | **`30 · 60`**（第三块 = **90**）| **fixture 实测** |
| ← 其余**留空** | | | 用户：「先做有据可查的」|

★ **`90°·90°`（语料 1411 处）不入表**：W=1 下第三块 = `180 − 180 = 0` ⇒ **不闭合**。
（除非确认它是 **W=2** ⇒ `[90, 90, 180]` = 2 拍；但那样三个按下的间隔已是 `33/33/66ms`，
**不像"同时"** ⇒ 需要用户另行确认。已问过，用户把话题转到判据上，**暂按"不入表"处理**。）

★ `30·60` 是 `θ, 2θ`，而 `15·15` / `30·30` 是 `θ, θ` —— 用户：「**不确定是不是巧合**」
⇒ **不当规矩**，就按表硬写。

★ **12.5°**：用户提过「三押一般 **12.5 度** 或 15 度三连」，但**语料里没有 12.5 的三押**
⇒ 先只放 `15·15`，12.5 要不要做**待定**。

### 10.2 三个实现决定（文档没写死的，这里交代清楚）

1. **反向写法的 Twirl 只放第一块薄格**（§6.3 / §8-4 的默认）。放两块会把 parity 翻回来
   ⇒ 变成另一种几何。**两种编码的有效 travel 序列逐位相同**已被 H 组钉住。
2. **四押 / 5押 ⇒ 那一格仍按双押插**（不是整格丢掉），另记 `extra_press` + 上屏
   「本轮跳过（只做双押/三押）」。理由：不许因为多了一条轨就**静默吞掉**本来能插的双押。
3. **`three_press` 开关只到代码层，没上新界面控件**（默认开）。用户口径是「这就是判据」，
   没有要开关；留参数是为了回归测试能一键关掉。
