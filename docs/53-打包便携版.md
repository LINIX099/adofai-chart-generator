#### ★★ 坑 ①：安装版的 userData **不是** `Beat Data Generator`

实测：装完之后宿主用的仍是 **`%APPDATA%\beat-data-generator\`**。
原因：`userData = %APPDATA%\<app.getName()>`，`app.getName()` 读的是 **app 自己 package.json 的
`productName`** —— 上游那个字段**是空的** ⇒ 回退到 `name`。
`build.productName`（`Beat Data Generator`）只决定**安装包/快捷方式/exe 名**，**不参与** `getName()`。
**症状**：按旧文档把插件放进 `Beat Data Generator\plugins\` ⇒ **插件永远不加载**（我们踩了）。
已更正 `bridge_plugin/README.md`；`.bat` 应该**两个候选目录都放一份**（无害）。

#### ★★ 坑 ②：`_cdp.js` 的 `main` 选择器只认 dev 的 `:5173`

打包版没有 dev server（URL 是 `.../app.asar/out/renderer/index.html`）⇒ 只认 5173 会回退到
`pages[0]`，而那往往是 **welcome 窗口**。于是 `__adocBridge` 一直 `undefined`，
**看着像「插件没加载」，其实是问错了页面**（我们在这上面绕了一圈）。
已修：`main` 现在也认 `/index.html`，并新增 `--target index`。

#### 小瑕疵（还没修）

插件在**没有音频**时会发一条 `{"type":"audio"}` 而**不带 `path`**，对端拒收
（插件日志：「对端说不行：audio 消息没有 path」）。无害但刺眼 —— 要么插件不发、要么对端收下空值。

### 0.3 便携版特有的三条（2026-10 补测，都是**真机踩出来的**）

**① 全新用户画像能起来**：用 `--user-data-dir=<空目录>` 跑 `--smoke` → PASS，
`logs/` 正常建。说明不依赖开发机上攒下来的任何状态（布局 / localStorage）。

**② ★ 打包版的「BDG 桥」原来在说开发者话** —— 用户点「启动并桥接」，弹的是

> 「先 `npm run host:fetch`（走代理 127.0.0.1:7897，约 600MB）」

拿到 zip 的人**没有 npm、没有仓库、更没有那个代理**，而且 `tools/host.js` 打包时
根本没带进去 ⇒ 这句话是**死胡同**。已修成用户能照做的三条：
装一份 BDG → 把包内 `resources\bridge_plugin` 放进它的插件目录 → 手动贴连接串。
按钮在便携版里**直接禁用**（带正确 tooltip），`hostctl.py` 也会在动手前先看
`tools/host.js` 在不在（`state.tool`），不在就返回人话而不是去跑 node。
顺带把**我们自己的插件**（`bridge_plugin/`，60KB，非 GPL）**随包带上** ——
否则用户装了自己的 BDG 也没东西可连。

**③ 验收脚本自己有过一个竞态**（记下来免得再犯）：`pack_verify.py` 一开始只等
CDP 端口通（Chromium ~3 秒就开）就开始驱动，而渲染进程还没 boot 完 ⇒ 抛一个
**看着像「产品坏了」的 TypeError**。已改成等应用自己说 ready（`__dsh` + health + 画布）。
**一个会偶发失败的验收脚本比没有验收脚本更糟** —— 它会让你怀疑产品。

## 1. 三个必踩的网络坑（先记这个，省一天）

| 坑 | 现象 | 解法 |
| --- | --- | --- |
| **pip 直连索引会「静默」失败** | `Could not find a version that satisfies the requirement numpy (from versions: none)` —— 看着像**没有轮子**，其实根本连不上索引（pip 连标签都能列、PyPI 上 `cp314` 轮子确实有） | **走代理 `127.0.0.1:7897`**（verge-mihomo，出口新加坡）。给 pip 设 `HTTP(S)_PROXY` 立刻下动 |
| **github.com:443 连不上** | `git fetch` / electron 二进制下载全挂 | git 用 **`ghproxy.net`** 当远端；electron 二进制用 **`ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`** |
| **python.org 下载会 read timeout** | 33.9MB 的包 60s 只下了几 MB | 走 **`registry.npmmirror.com/-/binary/python/`**（同一文件，秒下）。脚本里**镜像优先**、官方垫底 |

★ `tools/host.js` 里的 `DEFAULT_PROXY` 就是 7897 —— 早已在仓库里，别再造一个。


## 4. 壳：`app/package.json` 的 `build` 段 + `app/main.js` 的三处改动

- `ROOT`：打包后 `__dirname` 在 **asar 里**，`..` 会指到 `resources/` —— 而 `extraResources`
  正好把 `core/ sidecar/ patterns/ vendor/ samples/` 放在那儿 ⇒
  `ROOT = app.isPackaged ? process.resourcesPath : path.resolve(__dirname, '..')`。
- `pythonExe()`：`ADOFAI_PYTHON` > 包内 `resources/runtime/python/python.exe` > 系统 `python`。
- `logFile()`：★ 打包后 `__dirname/.logs` 在 **asar 里（只读）**，一启动就在 `mkdir` 上摔 ⇒
  改写到 `app.getPath('userData')/logs`。
- `extraFiles` 把 `packaging/使用说明.txt` 放到 **exe 旁边**（给拿到 zip 的人看）。
- `signAndEditExecutable: false`（不下 winCodeSign、我们不做签名）。
- `electronDownload.mirror` 指 npmmirror。
