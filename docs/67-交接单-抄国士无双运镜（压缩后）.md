### ③ ★★ 关键结构（**2026-10 复测修正**）

交接单初版写的「宏观层每 44~78 格重发一次」是**错的**。把 `1521..1778` 逐条摊开
重数之后，真实结构是「**微观成串 + 串尾弹回 + 长锚静默**」：

```
1569,1571,1573  微观 Tile（每 2 格一条）      ← 一串 3 条
1575            宏观 Player dur=4  OutCirc    ← 「弹回」，串尾一定有这一条
1579,1581,1583  微观（下一串）
1585            宏观 Player dur=32 OutCirc    ← 长锚（跨 256 格）
        …1585..1629 共 44 格**一条微观都没有**（长锚自己在走）
1629,1631,1633  微观
1635            宏观 dur=4 OutCubic
1647,1663,1713,1723,1737,1753,1767 …
```

| | 实测 |
|---|---|
| 微观串长 | **3 / 3 / 3 / 4 / 6 / 3 / 3 / 5 / 3 / 5** 条 |
| 串内间隔 | **2 格**（偶尔 3） |
| 弹回间隔 | **10~16 格**（`Player pos=[-4,3] zoom=300`，`dur=4` 拍） |
| 长锚 | `32` 拍 ≈ 256 格 / `64` 拍 ≈ 512 格，**后面的 44 格完全不发微观** |
| 该段合计 | 54 条镜头（≈ 每 4.8 格一条）**其中微观 38 条、宏观 12 条** |

⇒ **抄的时候两条都不能漏**：光有「连续微观」没有「串尾弹回 + 长锚静默」，
就不是国士那一套了（`tools/apply_camera_gs.py` 按这个结构实现）。

### ④ 进场（段前 `f1517..f1519`）

```
f1517  dur=4  补间  Tile    pos=[0,0]  zoom=120  OutElastic
f1519  dur=4  补间  Tile    pos=[0,0]  zoom=320  OutCubic
f1519  dur=4  补间  Tile    pos=[2,0]  zoom=1    ang=720  InBack     ← zoom=1 + 2 整圈
```

### ⑤ 为什么这一套重要

本项目 `docs/64` §9.2 的镜头分派是「**按 `cur` 二选一**」：
高 cur → 位置+呼吸+缓慢移动；低 cur → 一拍一振。
**国士無双 把两者叠在同一段里**，靠 `relativeTo` 分工（宏观 `Player` / 微观 `Tile`）
互不干扰 ⇒ **解掉了那个二选一**。这是 `docs/66` §9.4/§9.5 的「家族 E」。
