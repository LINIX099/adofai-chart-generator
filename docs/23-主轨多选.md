# 23 · 主轨改成多选（并集：哪条有音采哪条）

> 用户口径：「**这样，现在主轨也可以选不止一条了，哪条有音采哪条**」。
> 追问确认三件事：① 多条主轨之间取**并集**（按 `merge_ms` 合并，不再看补空白阈值）；
> ② 把「主轨选择」和「参与采音的轨」**合成一个概念** —— 主轨集合就是实际采音集合；
> ③ 双押轨不变，仍单独勾、不参与主轨并集。
> 前置：`docs/12` §14.7/14.8（当初为什么做「主轨+补空白」）、`docs/18`（旧 UI 施工图）。

---

## 1. 改了什么

### 1.1 概念收敛

| | 改之前 | 改之后 |
|---|---|---|
| 谁决定采哪些音 | `scope` 模式 + `primary_mode` 挑出的**单**主轨 + `tracks_checked` 补空白轨，三者联动 | **`主轨 = tracks_checked`（多选），勾哪几条就采哪几条，取并集** |
| 合并方式 | mode 0 `build_onsets_fill(主轨, 补空白轨, 阈值)`；mode 1 单轨；mode 2/3 多轨全采 | 一律 `build_onsets_multi(勾选的轨)` |
| 补空白阈值 | `fill_gap_ms`（mode 0 用） | **删除**（并集已经覆盖它） |
| 主轨启发式 | `primary_mode` 5 档（手动 + 平均音高/力度/音符数/音域） | **删除**（主轨现在是显式多选） |
| 区间采音 | 每个区间带 `mode` + `fill_gap_ms` | 区间只有 `tracks`，同样**取并集** |

删掉的 schema 字段：`scope`、`primary_mode`、`fill_gap_ms`（共 3 个）。
`core/onsets.py` 里 `build_onsets_fill` / `notes_fill_gaps` **保留** ——
`tools/` 下还有几个诊断脚本在用，只是 sidecar 不再走这条路。

### 1.2 默认只勾一条

`load()` 原来把「全部非鼓轨」设为默认勾选——那在旧模型下是「候选集」，
在新模型下就变成**默认全采**了。实测 `doublepress_demo_120.mid`：

| 默认勾选 | onset | 直线率 | SetSpeed |
|---|---|---|---|
| 全部非鼓（= 全采） | 328 | **15%** | 158（48%） |
| 启发式最优那一条 | 155 | **39%** | 44（28%） |

所以默认改成**只勾启发式最优的那一条**（平均音高最高的非鼓轨，`pick`），
想要并集自己多勾几条。开箱结果从「又密又碎」回到「干净的单声部线」。

## 2. 顺手挖出来的一个哑弹（★ 值得单独记）

**自动改写的音高过滤会把你显式选中的轨偷偷滤没。**

`derive()` 每次勾选变化都会把 `pitch_lo/hi` 覆写成「所选轨音高的 min/max」
（这是旧 UI 的行为，前端会提示）。但这份过滤被**一律套用到所有采音路径**上：

- **双押轨**：`accent-bell` 当主轨 → `pitch = 91..91`；双押轨是节拍器（音高 ~50）
  → 整条被滤空 → `dp_t` 为空 → **双押一处都插不进去**。
- **区间轨**：区间指定 `melody` 轨（音高 ~65），主轨是 `91..91` → 区间采出 **0 个点**。

这个哑弹一直都在，只是旧默认（主轨 + 补空白）的音高范围更宽，恰好盖住了它。
主轨变窄之后立刻爆出来（e2e 直接红）。

**修法**：`derive()` 的音高建议改为覆盖「用户**在任何地方**显式选中的轨」=
主轨 ∪ 区间轨 ∪ 双押轨。这样自动过滤永远不会杀掉你自己挑的轨，
而用户**手动**设置的音高过滤依然生效。

> 我先写的是「双押轨单独关掉音高过滤」，后来发现区间轨是同一个毛病，
> 就换成了上面这个一处修好的做法 —— 同一个病因，不要在两个地方各打一块补丁。

## 3. 前端

- ② 分组标题 → 「② 主轨（勾选要采音的轨，可多选）」；列表小标题 → 「主轨（可多选）：勾哪几条就采哪几条，取并集」
- 删掉 `scope` / `primary_mode` 两个下拉框、以及区间编辑器里的「模式」下拉
- 只读提示（`#lbl-track`）改成：`主轨 ['trk2', 'trk3'] 取并集 · 483 个 note-on · 双押轨 [1]`
- 新增调试钩子 `setTracks(list)`：**必须走它**，它会连带改写 `pitch_lo/hi`
  （直接写 `state.tracks_checked` 会留下上一次选择的音高过滤 —— 实测 483 note 只剩 155 onset）

## 5. 踩到的两个测试坑（避免下次再踩）

1. **角度双押在过密谱面上无处可插**：并集 328 onset 时角度双押实测 **0 处**
   （单主轨 155 onset 时是 19 处）。所以「能插层」这类断言必须用**稀疏**的谱面，
   否则会假失败。
2. **不要绕过前端改勾选**：直接写 `state.tracks_checked` 不会触发 `derive` 的
   音高改写，留下一份过期的过滤把音滤掉。

排查脚本：`tools/_track_probe.py`（打印每条轨的 notes/鼓/平均音高/首个音时刻，
以及几种主轨选择 × 两种双押模式下各自的 onset 数、层数、双押命中数）。
