# 09 · 硬规则落地（速度档 / Twirl / 自检）

> 这一版只做一件事：把你定下的**硬规则**写进生成器，并加一个自检器。

---

## 你定的规则 → 现在的实现

| 规则 | 实现 |
|---|---|
| **速度档只用 2 的幂**（×2/×4/×8 及倒数） | `SPEED_TIERS = (1/8, 1/4, 1/2, 1, 2, 4, 8)`（k = BPM 除数，行星速度 = 1/k）。之前用的 `1/3` 已删除 |
| **Twirl 和 SetSpeed 不能同一格** | `solve._finish()`：落地前把撞格的 Twirl 往后挪到第一个空位；`writer.build_actions()` 再兜一层 |
| **不用中旋** | 从来没写过 999 |
| **第 0 格必须直线** | 强制 `travel[0] = 180°`、`angleData[0] = 0` |
| **不出现回头方块** | travel 软约束 `[20°, 340°]`，硬约束 `[2°, 358°]`；超长休止退回「离 r 最近的 2 的幂」 |
| **重叠（遮挡）** | **不做严格检查**（你说没必要）。只在选 Twirl 时倾向把路径铺开 |

新增 `core/rules.py`：`check_chart()` 返回违规清单，`summary()` 出人话。
UI 状态栏每次生成后显示 `规则检查 ✓` 或 `⚠ 规则检查 N 条不合格`。

另外加了 `speed_penalty = 0.35`（每偏离基准速度一个八度的代价），
防止 DP 为了多几条直线就乱用 ×8。

---

## 实测（三个样本，平衡档）

| 样本 | 直线 | SetSpeed | 同格冲突 | 速度档 k | 回头 | a[0] |
|---|---|---|---|---|---|---|
| FallenEra | **66%** | 44 | **0** | 1/2, 1, 2, 4, 8, 16 | 0 | 0 |
| Automaton_Waltz | **78%** | 164 | **0** | 1, 2, 4, 8 | 0 | 0 |
| MemoryLocked | **54%** | 30 | **0** | 1, 2, 4, 8, 512 | 0 | 0 |

- k = 16 / 512 是**长休止**（MemoryLocked 有 226 拍空档），仍是 2 的幂 ✓
- 速度范围被 `speed_penalty` 压在 0.06×~4×（之前会到 8×）
- 时序误差 ≤ 0.2ms（来自 MIDI tempo 截断，见 docs/08）

`tools/_verify_rules.py` 直接读导出的 `.adofai` 复核，全部 ✓。
