### 2.1 `load_midi(path)`（`main_window.py:568-658`）

1. **分流**：`path.lower().endswith(AUDIO_EXTS)`，其中 `AUDIO_EXTS = (".ogg",".oga",".wav",".flac",".mp3")`（`:38`）。
   - 音频分支（`:570-597`）：弹 `QProgressDialog`（标题「音频 → 音头」，`setMinimumDuration(0)`、`setAutoClose(False)`、`setAutoReset(False)`），

     用户取消时抛 `audio_mod.ConversionCancelled()`。
     调 **`audio_mod.load_as_midi(path, progress=_prog)`** → `self.midi`（`:589`）；
     取消则 `status("已取消音频转换")` 并 return（不改变 `self.midi`）；成功后 **`self.source_audio = path`**（`:597`）。
   - MIDI 分支（`:598-600`）：**`midi_mod.load(path)`** → `self.midi`；`self.source_audio = None`。

2. `self.midi_path = path`；`self.audio_path = self.source_audio`；`self._audio_key = None`；`self.stop()`（`:604-608`）。
3. `lbl_file.setText(basename + "\n" + self.midi.stats())`（`:609`）。
4. **填音轨列表**（信号阻断，`:611-621`）：对 `self.midi.tracks` 每条 `t`：
   `QListWidgetItem(onsets_mod.track_summary(t))`，`UserRole = t.index`，加 `ItemIsUserCheckable`，

5. **scope 归位**（`:622-626`）：`cb_scope.currentIndex() == 0` 时什么也不做（注释说明默认就是这个），否则 `setCurrentIndex(0)`。
6. **主轨光标默认**（`:627-637`）：`cand = [t for t in midi.tracks if t.notes and not t.is_drum_only()]`，
   取 `max(cand, key=lambda t: (avg_pitch, len(notes)))` 的 `index`；在 `lst_tracks` 里按 `UserRole` 找回行号并 `setCurrentRow`。`cand` 为空时 `pick = 0`。
7. **填双押轨列表**（信号阻断，`:640-654`）：每行文字 `f"双押轨 trk{t.index} {t.name or '(无名)'}（{len(t.notes)} 音·{架子鼓|旋律}）"`，
   `UserRole = t.index`，`checkState = Checked if (t.notes and t.is_drum_only())`。
8. `ed_song.setText(文件名去扩展名)`；`status(...)`；最后 **`self._on_track_changed()`**（`:656-658`）。

### 2.2 选轨派生（纯 UI 逻辑，不调 core）

- `_current_track()`（`:660-662`）：`lst_tracks.currentItem()` 的 `UserRole`，无则 0。
- `_checked_tracks()`（`:664-670`）：所有 `Checked` 行的 `UserRole`。
- `_primary_track()`（`:672-701`）：
  - mode 0（手动）：光标轨若 `0 <= ti < len(tracks)` 且有音 → 直接返回；否则退到第一条**已勾选且有音**的轨；再否则 0。
  - mode 1/2/3/4：候选 = 已勾选 且 有音 且 非鼓 的轨；为空 → 所有有音的轨；再为空 → 0。
    key 分别为 `(avg_pitch, len)` / `(avg_vel, len)` / `(len, avg_pitch)` / `(span, len)`，`max` 取胜（`:697-700`）。
- `_dp_tracks()`（`:717-728`）：`lst_dp` 里勾选且该轨有音 的轨号列表。
- `_filler_indexes()`（`:750-759`）：`checked - {prim} - dp`；mode 3（含鼓）不限鼓，否则再排除 `is_drum_only()`。
- `_selected_track_indexes()`（`:761-773`）＝ 实际采音轨：
  mode1 → `[prim]`（该轨有音时）；mode2/3 → `checked - dp`；mode0 → `[prim] + _filler_indexes()`。
- `_on_scope_changed(idx)`（`:775-785`）：**改写所有 `lst_tracks` 勾选态**（`want = bool(t.notes) and (idx == 3 or not t.is_drum_only())`），
  阻断信号后调 `_on_track_changed()`。注意：这一步会把用户手动的勾选全部覆盖。
- `_on_primary_changed`（`:703-715`）：非手动模式时，把光标移到 `_primary_track()` 那一行（阻断信号），然后 `_on_track_changed()`。
- `_on_track_changed()`（`:790-830`）：刷新 `lbl_track` 文案 → 若光标轨有音，先把 `sp_plo/sp_phi` 设为**该轨**的音高 min/max；
  再对所有 `_selected_track_indexes()` 的音符取**并集** min/max 覆盖一次（`:822-829`）；最后 `_schedule()`。

### 2.3 `rebuild()` 精确顺序（`main_window.py:890-1068`）

1. `if not self.midi: return`。
2. `used = self._selected_track_indexes()`（`:894`）；为空 → `status("没有可采音的音轨（②里勾选一下，或换成「多轨」）")` 并 return（`:895-897`）。
3. `mode = cb_scope.currentIndex()`；`p_on = self._params_onset()`（`:898-899`）。
4. **`self.onsets`**（`:900-911`）：
   - mode 0：`onsets_mod.build_onsets_fill(self.midi.tracks[prim], [tracks[i] for i in fil], p_on, self.sp_fillgap.value())`
   - mode 1：`onsets_mod.build_onsets(self.midi.tracks[prim].notes, p_on)`
   - mode 2/3：`onsets_mod.build_onsets_multi([tracks[i] for i in used], p_on)`
5. `merged_notes = [n for i in used for n in self.midi.tracks[i].notes]`（`:912`）。
   若 `len(self.onsets) < 2` → `status("采音点少于 2 个，无法成谱。放宽过滤条件试试。")` 并 return（`:913-915`）。
6. `p_sv = self._params_solve(self.onsets)`（`:917`）—— 见 2.4。
7. **`self.chart = solve_mod.solve(self.onsets, p_sv)`**（`:919`）；`cd = self.sp_cd.value()`（`:920`）。
8. **双押插入（必须在所有派生量之前，`:922-980`）**：`self.dp_info=""`、`self.dp_report={}`、`n_dp=0`；
   若 `dp_tis and len(self.chart.floors) > 2`：
   - `dp_t`：对每条双押轨再跑一次 `onsets_mod.build_onsets(track.notes, self._params_onset())`，收集 `o.t_ms` 后排序（`:931-936`）。
   - `tol = float(sp_dptol.value())`；`lead = 1 if chart.meta.get("n_lead") else 0`；
     `pre = solve_mod.times_from_chart(self.chart)`；`main_t = [o.t_ms for o in self.onsets]`（`:938-941`）。
   - **目标层 `tg`**（`:943-950`）：双指针扫描，`main_t` 里每个 `T` 若在 `dp_t` 中存在 `T-tol <= dp_t[j] <= T+tol` 的音头，
     就 `tg.append(pre[min(k + lead, len(pre)-1)])`（**永远是主音那一层**）。
   - **空过计数 `skipped`**（`:952-959`）：双押轨音头里，主音当时没有任何音头落在 ±tol 内的个数。
   - 分流（`:962-980`）：`cb_dpmode.currentIndex()==1` → `dp_angle.plan(chart, tg, report=rep)` + `dp_angle.apply(chart, plan)` + `dp_angle.stats(chart)`；
     否则 `dp_midspin.plan` / `dp_midspin.apply`。
     写出 `self.dp_report`（含 `dp_onsets/dp_hits/dp_skipped/dp_extra`，角度双押额外 `reverse/normal`）和 `self.dp_info`。
9. **派生量**（`:982-994`）：
   - `self.preview_lead_ms = solve_mod.total_lead_ms(self.chart, cd)`
   - `self.chart_entry = solve_mod.game_entry_times(self.chart, cd)`
   - `self.chart_times = solve_mod.times_from_chart(self.chart)`
   - `self.hit_times`：`o2n = chart.meta.get("dp_old2new") or {}`；`nf = len(floors)`；`lead` 同上；
     对每个 onset i：`j = min(i+lead, nf-1)`，`j = o2n.get(j, j)`，`hit_times.append(self.chart_entry[min(j, nf-1)])`。
     **注释明确说明不能直接用 `entry_time_of_onsets()`**，因为插了中旋后层号整体后移（`:985-994`）。
   - 附：`solve_mod.path_overlap_stats(self.chart)`、`solve_mod.speed_profile(self.chart)` 的结果 `ov`/`sp` 被赋值但**之后未使用**（`:995-996`）。
10. **自动 offset**（`:998-1001`）：若 `cb_autooffset.isChecked()` → `sp_offset.blockSignals(True)` → `setValue(self.onsets[0].t_ms)` → `blockSignals(False)`。
11. **喂视图**（`:1003-1012`）：
    - `self.roll.set_data(merged_notes, self.onsets, self.midi.length_ms, beats_ms=self._beat_grid_ms())`
    - `self.pathv.set_data(self.chart.floors, self.chart_entry, 0.0)`
    - `self.chartv.set_data(self.chart.floors, self.chart_entry, 0.0, bpm0=self.chart.base_bpm, dp_pairs=self.chart.meta.get("dp_pairs"))`
    - `self._update_chartview()`；`self._update_falling()`
12. **统计与自检**（`:1014-1054`）：
    - `mild = [f.bpm / chart.base_bpm for f in floors[1:] if f.speed_k <= max(SPEED_TIERS)]`（排除长休止层）
    - `chk = solve_mod.check_offset(self.chart, self.sp_offset.value(), cd, [o.t_ms for o in self.onsets], self.midi.length_ms + self.preview_lead_ms, self.preview_lead_ms)`
      （第 6 个参数 `shipped_shift_ms` 传的就是 `preview_lead_ms`）
    - `rhythm.extract(self.onsets, midi.ppqn, 60000.0 / max(1e-9, midi.bpm0))` → `_rhythm_txt`（异常时 `"—"`）
    - `chart.travel_hist(4)` → `hist_txt`
13. `lbl_timing.setText(...)`（`:1032-1039`）；`status(msg)`（`:1043-1067`，含
    `rules.check_chart(chart)` 的违规计数、雪花朵数、双押信息、`chk['max_err_ms']`（勾了自动 offset）
    或 `chk['suggest_ms']`（没勾））；最后 `self._refresh_time_label()`（`:1068`）。
    `n = len(self.chart.floors)`；`n_pause = sum(1 for f in floors if f.pause_beats > 1e-9)`；`n_tpl/n_tpl_cov` 取 `chart.meta`。

### 2.4 `_params_solve(onsets)` 的「自动」分支（`main_window.py:846-887`）

1. 先把 UI 直映射写进 `SolveParams`（见 §1 ④ 的字段列）。
2. `if self.cb_autobpm.isChecked()`（`:875-883`）：
   - `beats, _ = solve_mod.beats_of(onsets, ppqn, mbpm or 120.0)`（tick 精确拍数；`core/solve.py:570-588`）
   - `C, bpm, _, _, _ = solve_mod.choose_reference(beats, p, mbpm or 120.0)`（`beats` 为空则四元全 0）
   - `if bpm <= 0:` → `bpm = solve_mod.auto_base_bpm(onsets, 180.0, 0.85, ppqn=ppqn, midi_bpm=mbpm)`
   - **只回填显示**：`sp_bpm` 在 `blockSignals(True/False)` 包裹下设为该 bpm。`p.base_bpm` **保持 0**，
     真正的基准 BPM 由 `core.solve.solve()` 内部再算一次（`core/solve.py:1026-1030`，并过 `_snap_nice`）。
3. `else`（`:884-886`）：`bpm = self.sp_bpm.value()`；`p.base_bpm = bpm`。

### 2.5 `_beat_grid_ms(division=4)`（`:1070-1083`）

按 `midi.bpm0` 生成节拍线：`step = (60000/bpm0) * 4.0 / division`（默认 division=4 ⇒ 1/16 音符步长），
从 0 递增，**只取前 30 秒**（`t < min(midi.length_ms, 30000.0)`）。注意它只用 `bpm0`，不跟 tempo map 走。

### 2.6 `export_chart()`（`main_window.py:1260-1300`）

1. 无 `self.chart` → `status("还没有生成谱面。")` 并 return。
2. `QFileDialog.getExistingDirectory("选择导出目录（会新建一个曲目文件夹）")`；取消则 return。
3. `name = (ed_song.text() or "main").strip()`，滤掉 `\/:*?"<>|`，再 strip，仍空则 `"main"`；`outdir = os.path.join(d, name)`（`:1267-1269`）。
4. `wav = self._audio_for_current()`（`:1271`）。
5. **`writer.write_dir(self.chart, outdir, name="main", audio_src=wav, song=..., artist=..., author=..., offset_ms=sp_offset, difficulty=sp_diff, countdown_ticks=sp_cd, separate_countdown=cb_sepcd)`**（`:1272-1279`）。
   异常 → `QMessageBox.critical("导出失败")` 并 return。
6. 复算 `chk = solve_mod.check_offset(chart, sp_offset, cd, onset_times, midi.length_ms + preview_lead_ms, preview_lead_ms)`（`:1286-1289`）。
7. `vr = verify.verify_file(p, [o.t_ms for o in self.onsets], tol_ms=1.0, lead_floors=1)`（`:1285`）。
8. `QMessageBox.information("导出完成", msg)`：路径、audio 是否随包、层数/直线率/Twirl/减速事件、
   `countdownTicks`/`offset`/前置静音、`chk['tail_gap_s']`、`vr.summary()`；`status(vr.summary())`。

  - 拖动 → `cx = cx0 − Δx/sc`，`cy = cy0 + Δy/sc`，`follow=False`（`:196-203`）。

  - `leaveEvent` 清 `_hover`（`:233-235`）。

  `floors` = `chart.floors`，`times` = `chart_entry`（游戏语义 entryTime），`base_ms=0.0`，`bpm0=chart.base_bpm`，
  `dp_pairs=chart.meta["dp_pairs"]`（`:1008-1010`）。播放头 `set_playhead_ms(ms)` 用 `bisect_right(times, ms − base_ms) − 1`（`:140-147`）。
  - `_find_bad()`（`:123-138`）：只与**前 32 格**（`RECENT=32`）比，距离平方 < `NEAR_R²=1.0` 就双向加入 `_bad`。只在 `set_data` 算一次。

  - `_rot[i] = -(f.angle if f.angle≠999 else 0)`（`:97-98`）。
  - `_paint_grid` 以当前格为锚画 ±40 条等距横线（世界格距 `TILE_STEP`），其中 `beat_px` 是死代码（`:361-375`）。

### 3.4 `FallingView`（`ui/falling_view.py`，页签「4K 下落式（验采音）」）

- **画什么**：4K/8K 下落式。

    重置 `chart_time/_last_time/_press_until`（`:63-75`）。
  - `set_time(ms)`：跨越 `press_time` 时把该 lane 记入 `_press_until[lane] = press + 180`（触发判定框回弹），
    用 `bisect_right` 做区间（`:81-91`）。`reset()` 全部清零（`:93-97`）。
  - 数据来自主窗口 `_update_falling()`：`notes = self._falling_notes(lanes)`、`caps = self._cap_times_ms(div)`，
    再 `falling.set_chart(chart.base_bpm, notes, lanes, speed=sp_speed, division=div, cap_times=caps)`（`:1113-1121`）。
  - `_falling_notes(lanes)`（`:1138-1166`）：`press[i] = offset + hit_times[i]`；`release_time = press[i+1]`（最后一个为 `None`）；
    `is_hold` 恒 `False`。lane 分配：`按音高分位` → `(bisect_right(ranked,pitch)−0.5)/len(ranked)*lanes`；
    `按音高线性` → `round((pitch−lo)/span*(lanes−1))`；`左右交替` → `i % lanes`；最后钳到 `[0, lanes−1]`。
  - `_cap_times_ms(div)`（`:1123-1136`）：`step = (60000/base_bpm) * 4.0 / div`；
    `t0 = offset + chart_entry[1]`，`end = offset + chart_entry[-1]`；`t` 从 `t0 − ((t0−offset) % step)` 起按 step 递增。

## 4. 播放与时间轴

### 4.1 音频来源 `_audio_for_current()`（`main_window.py:1169-1195`）

1. `if not self.midi: return None`。
2. **OGG/音频分支**：`if getattr(self, "source_audio", None) and os.path.exists(self.source_audio): return self.source_audio`（`:1173-1174`）。
   ⇒ **直接返回原始音频文件，不做任何渲染、也（见 §6 风险 2）不前置静音**。
3. **合成分支**（没有音源时）：
   - `idxs = self._selected_track_indexes() or [self._current_track()]`
   - 缓存 key = `(self.midi_path, tuple(idxs), len(self.onsets), round(sp_merge,3), sp_minvel, round(sp_minint,3))`；
     key 命中且 `self.audio_path` 存在 → 直接复用（`:1176-1180`）。
   - 否则 `tempfile.mkdtemp(prefix="adofai_preview_")` 下建 `preview.wav`；`status("正在渲染预览音频…（无音源，用内置合成音色）")`；
     `QApplication.setOverrideCursor(Qt.WaitCursor)` + `processEvents()`（`:1181-1185`）。
   - `synth.render(self.midi, wav, track_index=idxs[0], track_indexes=idxs, onsets=self.onsets, click=True, lead_ms=getattr(self,"preview_lead_ms",0.0))`（`:1187-1190`）；
     `finally` 恢复光标；写回 `audio_path` / `_audio_key`。
   - **注意**：`preview_lead_ms` 是 `rebuild()` 才产生的；未 rebuild 先播放时用 `0.0`。

### 4.2 各函数行为

| 函数 | 位置 | 行为 |
|---|---|---|
| `toggle_play` | `:1197-1219` | ① 正在播放 → `player.pause()`，按钮回 `▶ 播放`，return。② 无 midi → `status("先加载一个 MIDI。")`，return。③ `if not self.onsets: self.rebuild()`。④ `p = _audio_for_current()`，为 None 则 return。⑤ 源不同则 `player.setSource(QUrl.fromLocalFile(p))`。⑥ 处于 Paused → 直接 `play()`；否则 `falling.reset()`、`pathv.cur_floor = 0`、`setPosition(0)`、`play()`。⑦ 按钮变 `⏸ 暂停`。 |
| `stop` | `:1221-1223` | `player.stop()`；按钮回 `▶ 播放`。（`load_midi` 末尾会调用它，`:608`） |
| `seek(ms)` | `:1225-1228` | `if self.player.source().isEmpty(): return`；否则 `setPosition(int(ms))`。**不检查 chart 是否生成**。 |
| `_on_slider` | `:1230-1233` | 绑定在 `slider.sliderReleased`（`:522`）：`d = duration()`；`d>0` 时 `setPosition(int(slider.value()/1000*d))`。 |

| `_on_pos(ms)` | `:1239-1249` | ① `d = duration()`，`d>0` 时在 `blockSignals` 包裹下更新滑块值 `int(ms/d*1000)`。② 依次驱动四视图：`roll.set_playhead(ms)`、`pathv.set_playhead_ms(ms)`、`chartv.set_playhead_ms(ms)`、`falling.set_time(ms)`。③ `_refresh_time_label(ms, d)`。 |
| `_refresh_time_label(ms=None,d=None)` | `:1251-1257` | 缺参时取 `player.position()` / `player.duration() or 0`；格式函数 `f(v) = f"{v//60000}:{(v%60000)/1000:05.2f}"` ⇒ **`分:秒.百分秒`，如 `0:00.00` / `1:23.45`**；写入 `lbl_time` 为 `"pos / dur"`。 |
| `_update_follow()` | `:1085-1087` | 只同步 PathView：`pathv.follow = cb_follow.isChecked()` + `update()`。（ChartView 的跟随走 `_update_chartview`，是两个独立开关。） |
| `seek_floor(floor)` | `:1103-1111` | 连 `chartv.seekRequested`（`:456`）。`if not chart or not (0 <= floor < len(chart_entry)): return`；否则 `self.seek(self.chart_entry[floor])`。注释说明：预览音频开头补过 `preview_lead_ms` 静音，所以音频位置与 `chart_entry` 同一时间轴，**不加减 offset**。 |
| `_update_chartview()` | `:1089-1097` | 把 `cb_cfollow`/`sp_cspan`/`cb_ctravel`/`cb_cbad` 同步到 `chartv.follow/span/color_mode/show_bad` 后 `update()`；`if not self.chart: return`（在赋值之前就返回，所以 chart 为空时这 4 个控件不生效也不报错）。 |

**时间轴口径小结**（复刻时最容易错的一点）：
- 视图内部时间轴 = **游戏 entryTime 轴**（`chart_entry`，含 `(cd−1)` 拍倒计时 + 第 0 层 180°）。
- 播放头传入的是**音频毫秒**，视图直接 `rel = ms − base_ms`（`base_ms` 恒为 0.0）去 `bisect` `times`，
  即假设「音频轴 == entryTime 轴」（对合成音频成立，因为它前面补了 `preview_lead_ms`）。
- 下落式的时间轴是**成品音频轴**：`press = offset + hit_times`（`:1147`），切分线同样 `+offset`。
- 因此 `offset` **只影响下落式与 `_cap_times_ms`**，不影响 ChartView/PathView/PianoRoll 的播放头定位。

## 6. 迁移风险清单（Electron 易漏 / 必须特别实现）

1. **无滚轮抢焦的 `NoWheelFilter`（全局事件过滤器）** — `main_window.py:45-58, 109-112`。
   现象：只有**已经拿到键盘焦点**的 `QAbstractSpinBox`/`QComboBox` 才响应滚轮，其余一律 `ev.ignore()` + `return True`；
   否则「滚参数面板」会变成「悄悄改掉某个数值」。Electron：数值输入在非 focus 状态下必须吃掉/忽略 `wheel`，
   且过滤器安装在 **QApplication** 级（`installEventFilter`），不是逐个控件 —— 逐个注册必然漏掉后加的控件。
2. **导出音频的「前置静音」口径在两条分支上不一致** — OGG 分支 `:1173-1174` 直接返回原音频，
   合成分支 `:1187-1190` 才 `lead_ms=preview_lead_ms`；而 `writer.write_dir(audio_src=wav)`（`:1272-1273`）
   对 OGG 只是 `shutil.copy2` 原文件（`core/writer.py:240-252`），**没有任何地方给 OGG 补 (cd 拍) 静音**，
   尽管 `cb_autooffset` 的 tooltip 承诺了这件事（`:417-420`）。
   同时 `check_offset` 的第 6 参 `shipped_shift_ms` 被硬编码成 `preview_lead_ms`（`:1018-1021, 1286-1289`），
   这对合成音频成立、对原曲 OGG 可疑（? `:1173` 与 `:1020` 的口径冲突）。
   Electron 必须先定义清楚「导出音频是否含前置静音、offset 是相对谁」，否则预览与游戏对不上。
3. **`check_offset` 的两种 offset 口径 + 自动 offset 的写回回路** — `:998-1001` 里
   `sp_offset` 在 `blockSignals` 保护下被改写；`:1052-1054` 用「勾了=命中误差 / 没勾=建议 offset」两套文案；
   `check_offset` 返回 `max_err_ms` 与 `suggest_ms`（`core/solve.py:1533-1558`）。
   风险：Electron 用响应式状态时，「offset 变化 → rebuild → 自动改写 offset」会形成**无限重建循环**；
   必须复刻「程序写值时不触发重建」的语义。
4. **`sp_plo` / `sp_phi` 每次换轨都被自动覆写** — `:822-829`：先按光标轨 min/max，
   再按 `_selected_track_indexes()` 的并集 min/max 覆盖。用户手改的音高过滤会被下一次 `_on_track_changed` 冲掉。
   这既是「特性」（多轨必须取并集）也是坑，Electron 要么原样复刻、要么显式改成「手动锁定」。
5. **`_on_scope_changed` 会重置全部音轨勾选** — `:775-785`：改 `cb_scope` 立刻按
   `want = bool(t.notes) and (idx==3 or not is_drum_only())` 重写所有勾选态。
   另 `load_midi` 里有段**死代码**：`if cb_scope.currentIndex()==0: pass`（`:622-624`），语义靠 `_on_scope_changed` 之外的手动初始化。
6. **音轨勾选 / 主轨光标 / 双押轨三者互相联动** —
   `lst_tracks.itemChanged → _on_track_changed`（`:238,787-788`）、`currentRowChanged → _on_track_changed`（`:237`）、
   `lst_dp.itemChanged → _on_track_changed`（`:208`）、`cb_primary` 非手动时会**移动光标行**（`:703-715`，且 `blockSignals`）。
   复刻时任何一条边漏掉，主轨判定（`_primary_track` 的手动/启发式分流）就会与旧 UI 不同。
   另注意双押轨**默认勾鼓轨**（`:649-650`），且勾了的轨会从采音集合里剔除（`_filler_indexes`/`_selected_track_indexes`，`:750-773`）。
7. **双押插入的时机与层号重映射** — `:922-994`。必须在 `solve()` 之后、`total_lead_ms/game_entry_times/times_from_chart/hit_times` **之前**做；
   `hit_times` 用 `chart.meta["dp_old2new"]` 重映射（`:987-994`），注释明确说不能用 `entry_time_of_onsets()`。
   同时 `dp_info`/`dp_report` 的统计（含 `dp_skipped` 的 ±tol 双指针、`lead = 1 if meta["n_lead"]`）也要照搬。
8. **140ms 防抖重建** — `_rebuild_timer`：`setSingleShot(True)`、`setInterval(140)`、`timeout→rebuild`（`:104-107`），
   `_schedule()` 只是 `start()`（`:832-833`）。Electron 若每次 `input`/`change` 都重建会卡死；
   但「重新生成」按钮和 `_on_track_changed` 的后半段走的是同一条 timer，唯一的**立即**重建入口是 `:438` 的按钮与
   `toggle_play` 里的 `if not onsets: rebuild()`（`:1205-1206`）。
9. **哪些控件不进防抖** — `ed_song/ed_artist/ed_author/sp_diff` **没有**连 `_schedule`（`:425-431` 只连了 `sp_cd/sp_offset/cb_sepcd/cb_autooffset`），
   改名/改难度不触发重建，只在导出时读（`:1267-1279`）。别顺手把它们接进重建。
10. **`cb_autobpm` 的「显示值 ≠ 实际值」** — 自动模式下 `sp_bpm` 被回填显示（`:883`，带 `blockSignals`），
